Database connection leak (plugin bug). authorizedLayerAttributes calls self.get_roles(self.DBSession()) and never closes that session (https://github.com/camptocamp/c2cgeoportal/blob/master/docker/qgisserver/geomapfish_qgisserver/accesscontrol.py#L786). Each request leaves connections "idle in transaction". Once the pool (5 + 25) is full, the next request waits 30 s, the QGIS process aborts, and the client gets a 500. Restarting qgisserver clears it temporarily, which is why the GMF failures move around between runs.
