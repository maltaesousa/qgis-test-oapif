gmf project
===================

Read the `Documentation <https://camptocamp.github.io/c2cgeoportal/2.10/>`_

Checkout
--------

.. code::

   git clone git@github.com:camptocamp/gmf.git

   cd gmf

Build
-----

.. code::

  ./build

Run
---

.. code::

   docker compose up -d

Contributing
------------

Install the pre-commit hooks:

.. code-block:: bash

   pip install pre-commit
   pre-commit install --allow-missing-config --config=.pre-commit-config.yaml

.. Feel free to add project-specific things.
